# Инструкция для заказчика: заявки в Google Таблицу и уведомления на почту

Когда посетитель оставляет заявку на сайте, она:

1. **сохраняется в базе сайта** (всегда, ничего настраивать не нужно);
2. **добавляется строкой в Google Таблицу** — чтобы вести список заявок;
3. **приходит письмом на вашу почту** — чтобы не пропустить обращение.

Пункты 2 и 3 нужно один раз настроить на **ваших** аккаунтах Google и Resend. Ниже — что именно сделать. В конце — **итоговый чек-лист**: 4 значения, которые надо передать разработчику (или вписать в настройки сайта самостоятельно).

> Если пункт 2 или 3 не настроен — сайт продолжит работать, заявки будут сохраняться в базе и видны в админке. Просто не будет строки в таблице / письма. Ничего не сломается.

## Часть 1. Google Таблица для заявок

Здесь два шага: создать **таблицу** и создать **«робота» (сервисный аккаунт)**, который имеет право в неё писать.

### 1.1. Создать таблицу

1. Откройте **https://sheets.new** (создастся новая пустая Google Таблица).
2. Дайте ей понятное имя, например «Заявки с сайта».
3. Внизу переименуйте вкладку листа на **`Leads`** (двойной клик по названию вкладки → впишите `Leads`). Это важно — сайт пишет именно в лист с таким названием.
4. В первую строку впишите заголовки колонок (по желанию, для удобства):

   | A | B | C | D | E | F | G |
   |---|---|---|---|---|---|---|
   | Дата | Имя | Телефон | Email | Интерес | Машина | Сообщение |

5. Скопируйте **ID таблицы** из адресной строки. Адрес выглядит так:
   `https://docs.google.com/spreadsheets/d/`**`ВОТ_ЭТОТ_ДЛИННЫЙ_КОД`**`/edit`
   Длинный код между `/d/` и `/edit` — это и есть **ID таблицы** (значение `GOOGLE_SHEETS_ID`).

### 1.2. Создать сервисный аккаунт и ключ (Google Cloud)

Сервисный аккаунт — это технический «пользователь», от имени которого сайт пишет в таблицу. Делается один раз.

1. Откройте **https://console.cloud.google.com** (войдите под своим Google-аккаунтом).
2. Вверху слева создайте новый проект (кнопка выбора проекта → **New Project**), название любое, например `zayavki-sayt`. Дождитесь создания и выберите его.
3. Включите нужный API: меню **APIs & Services → Library** → найдите **Google Sheets API** → откройте → кнопка **Enable**.
4. Создайте сервисный аккаунт: **APIs & Services → Credentials → Create credentials → Service account**.
   - Имя любое, например `zayavki-writer` → **Create and continue** → роль можно не выбирать → **Done**.
5. Создайте ключ к нему: откройте созданный сервисный аккаунт (в списке Credentials) → вкладка **Keys** → **Add key → Create new key → тип JSON → Create**.
   - Скачается файл `*.json` — **это секрет, храните его как пароль, никому не пересылайте в открытых чатах.**

В этом JSON-файле есть два нужных поля:

- `client_email` — адрес вида `zayavki-writer@zayavki-sayt.iam.gserviceaccount.com` → это значение `GOOGLE_SERVICE_ACCOUNT_EMAIL`.
- `private_key` — длинный текст, начинается с `-----BEGIN PRIVATE KEY-----` → это значение `GOOGLE_PRIVATE_KEY`.

### 1.3. Дать роботу доступ к таблице

Иначе будет ошибка «нет доступа».

1. Вернитесь в вашу Google Таблицу.
2. Нажмите **Share (Настройки доступа)** в правом верхнем углу.
3. Вставьте адрес сервисного аккаунта (`client_email`, тот самый `...@...iam.gserviceaccount.com`).
4. Дайте ему права **Editor (Редактор)** → **Send/Share**.

### Что передать разработчику по таблице

- `GOOGLE_SHEETS_ID` — ID таблицы (из адреса).
- Сам **JSON-файл** ключа (из него разработчик возьмёт `client_email` и `private_key`).
  Либо, если вписываете сами: `GOOGLE_SERVICE_ACCOUNT_EMAIL` и `GOOGLE_PRIVATE_KEY`.

## Часть 2. Уведомления на почту (Resend)

Отправлять письма напрямую с почтового ящика (Gmail/Яндекс) через SMTP часто мешают блокировки провайдеров. Поэтому используем сервис **Resend** — он отправляет письма по защищённому каналу (HTTPS) и надёжно доходит. Бесплатного тарифа (до 3000 писем в месяц) с запасом хватает для уведомлений о заявках.

### 2.1. Быстрый старт (без своего домена)

Подходит, чтобы сразу начать получать письма о заявках на вашу почту.

1. Откройте **https://resend.com** → **Sign Up**.
2. **Регистрируйтесь на ту почту, куда хотите получать заявки** (например `pochta-zakazchika@gmail.com`).
   *Почему так: без подтверждённого домена Resend разрешает отправлять письма только на почту владельца аккаунта. Поэтому почта регистрации = почта получателя заявок.*
3. Подтвердите email (перейдите по ссылке из письма Resend).
4. В панели слева откройте **API Keys → Create API Key**.
   - Имя любое (например `Sayt avto`), права **Sending access** достаточно → **Create**.
   - Скопируйте ключ — он показывается **один раз**, начинается с `re_...`. **Это секрет.**

Значения для сайта в этом варианте:
- `RESEND_API_KEY` = ваш ключ `re_...`
- `EMAIL_FROM` = `onboarding@resend.dev` (служебный адрес-отправитель Resend)
- `LEADS_EMAIL_TO` = почта, на которую хотите получать заявки (= почта регистрации)



### Что передать разработчику по почте

- `RESEND_API_KEY` — ключ `re_...`
- почту-получателя заявок (`LEADS_EMAIL_TO`)
- (если делали домен) адрес отправителя (`EMAIL_FROM`)


## Итоговый чек-лист (что подготовить и передать)

**Google Таблица:**
- [ ] Создана таблица, вкладка листа названа `Leads`
- [ ] `GOOGLE_SHEETS_ID` (из адреса таблицы)
- [ ] JSON-файл сервисного аккаунта (в нём `client_email` + `private_key`)
- [ ] Таблица расшарена на `client_email` с правами **Editor**

**Почта (Resend):**
- [ ] Регистрация на resend.com (на почту-получатель заявок)
- [ ] `RESEND_API_KEY` (ключ `re_...`)
- [ ] Почта-получатель заявок (`LEADS_EMAIL_TO`)
- [ ] (опционально) подтверждённый домен и адрес отправителя `EMAIL_FROM`
